Filter

filter

Extract rows that meet some criteria

filter(.data = DATA, ...)

  • DATA = Data frame to transform

  • … = One or more conditions
    filter() returns each row for which the condition is TRUE

Tip: .data = is optional when piping

filter(.data = penguins, sex == "female") and penguins |> filter(sex == "female") do the same thing. When you use |>, the dataframe is passed in automatically — no need to write .data = explicitly.

Common mistakes

Using = instead of ==

# Wrong
filter(.data = penguins,
  sex = "females")

# Right
filter(.data = penguins,
  sex == "females")

Forgetting quotes

# Wrong
filter(.data = penguins,
       sex == females)

# Right
filter(.data = penguins,
       sex == "females")

Common mistakes

Collapsing multiple tests into one

penguins between 3000 and 5000 g

# Wrong
filter(.data = penguins,
       3000 < body_mass_g < 5000)

# Right
filter(.data = penguins,
       body_mass_g < 5000,
       body_mass_g > 3000)

Using multiple tests instead of %in%

penguins in Dream and Biscoe

# Wrong
filter(.data = penguins,
       island == "Dream",
       island == "Biscoe")

# Right
filter(.data = penguins,
       island %in% c("Dream", "Biscoe"))

Mutating multiple columns at once

To apply the same function to many columns you can use across() inside mutate():

penguins |>
  mutate(across(where(is.numeric), ~ round(.x, 1)))
  • across() — “apply the same transformation across multiple columns at once”
  • where(is.numeric) — “but only the columns where the data are numeric”
  • ~ round(.x, 1) — “the transformation to apply: round each value to 1 decimal place” (the ~ creates a small anonymous function; .x is a placeholder meaning “the current column”)

So the whole line reads: “For every numeric column, round its values to 1 decimal place.”

On your own, look up across() — it replaces the older mutate_if(), mutate_at(), and mutate_all() functions.

We’ll come back to this

The ~ syntax used inside across() are concepts we haven’t covered yet. We will revisit across() once we learn how to write our own functions. For now, just know it exists and what it does conceptually.

The pipe operator: |>

The pipe |>

The “pipe” says “and then do”

dataframe |>   # select the dataframe and then
  verb1() |>   # do verb 1 and then
  verb2()      # do verb 2

|>

me |>
  wake_up(time = "6:00") |>
  music(turn = "on", to = "Beyonce") |>
  shower(wash_hair = TRUE) |>
  get_dressed(pants = TRUE, shirt = TRUE) |>
  leave_house(car = TRUE)

The native pipe |>

The |> is built into base R (R 4.1+) — no package needed.

You may also see %>% (the magrittr pipe from tidyverse) in older code. They work the same in most situations. In this class we use |>.

Please Read Here!

Keyboard shortcut

Insert |> instantly with Ctrl+Shift+M (Windows/Linux) or Cmd+Shift+M (Mac).

To make sure RStudio inserts |> (not %>%): Tools → Global Options → Code → Use native pipe operator, |>

group_by

You can summarize values by certain groups.
group_by() by itself doesn’t do anything, but it is powerful when put before summarise().

Let’s calculate the mean, max, and count of bill length by island.

penguins |>
  group_by(island) |>
  summarise(mean_bill_length = mean(bill_length_mm, na.rm = TRUE),
            max_bill_length  = max(bill_length_mm, na.rm = TRUE),
            n                = n())
# A tibble: 3 × 4
  island    mean_bill_length max_bill_length     n
  <fct>                <dbl>           <dbl> <int>
1 Biscoe                45.3            59.6   168
2 Dream                 44.2            58     124

You may see a message like summarise() has grouped output by 'island'. This is just informational — dplyr is telling you the output is still grouped.

Pipe into a ggplot

You can connect your data wrangling to a ggplot with the pipe (you won’t need to call the dataframe in ggplot if you pipe to it).

Drop NAs from sex, and then plot boxplots of flipper length by sex.

penguins |>
  drop_na(sex) |>
  ggplot(aes(x = sex, y = flipper_length_mm)) +
  geom_boxplot()
