Warning

If your map looks like a tangle of crazy lines, what did you most likely forget?

group = group in your geom_polygon() aesthetic.

Without it, ggplot connects every vertex in one continuous path — it has no idea where one polygon ends and the next begins.

Getting Tile Basemaps with {maptiles}

{maptiles} downloads satellite and street map tiles
from free public providers directly into R.

What Is a Map Tile?

Online maps (Google, OpenStreetMap, ESRI) are not single images — they are made of thousands of small 256 × 256 pixel tiles stitched together.

  • Tiles are organized by zoom level and grid position
  • At zoom 1, a handful of tiles cover the whole world
  • At zoom 17, thousands of tiles cover a single neighborhood
  • {maptiles} figures out which tiles you need, downloads them, and stitches them into one image

Tip

This is exactly how Google Maps works — {maptiles} just accesses the same tiles directly, using providers that allow free access.

Step 1 — Define Your Area of Interest

get_tiles() needs to know what area to download. We give it a bounding box — a rectangle defined by its corner coordinates.

# Define a bounding box around Wailupe, Oahu
# xmin/xmax = westmost/eastmost longitude
# ymin/ymax = southernmost/northernmost latitude
wailupe_bbox <- st_as_sfc(
  st_bbox(c(xmin = -157.772, ymin = 21.267,
            xmax = -157.752, ymax = 21.281),
          crs = 4326) # crs = 4326 means WGS84 — the lat/lon system your GPS uses
)

Note

st_bbox() creates the bounding box rectangle.
st_as_sfc() converts it to an {sf} geometry object so {maptiles} can read it.
crs = 4326 specifies WGS84 — almost all GPS and web map data uses this coordinate system.

Step 2 — Download the Tiles

tiles_satellite <- get_tiles(
  wailupe_bbox,               # the area to download
  provider = "Esri.WorldImagery", # which tile source to use
  zoom = 16,                  # level of detail (3 = continent, 20 = building)
  crop = TRUE,                # clip to our exact bbox (vs. slightly larger)
  cachedir = here("Week_07", "data", "tiles_cache") # save tiles to disk
)

Tip

cachedir saves the raw tile images to disk. The next time you render this document, {maptiles} will read from disk instead of re-downloading. Always include this when building presentations.

What Does get_tiles() Return?

class(tiles_satellite)
[1] "SpatRaster"
attr(,"package")
[1] "terra"

A SpatRaster — a raster image (grid of pixels) from the {terra} package.

  • A raster is just a matrix of pixel values — like a photo
  • tiles_satellite has 3 layers: red, green, and blue
  • We can’t use geom_raster() because that expects a data frame, not a terra object
  • {tidyterra} bridges this gap with geom_spatraster_rgb()
terra::nlyr(tiles_satellite) # number of layers (R, G, B)
[1] 3

Step 3 — Plot with geom_spatraster_rgb()

# geom_spatraster_rgb() is from {tidyterra}
# It reads the 3 color layers and renders them as a photo
ggplot() +
  geom_spatraster_rgb(data = tiles_satellite) +
  coord_sf(crs = 4326) +
  theme_minimal()

Note

coord_sf(crs = 4326) tells ggplot to treat your axes as geographic coordinates in WGS84. Always include it when plotting spatial data — it ensures the map is not distorted and that scale bars will work correctly later.

Zoom Levels

The zoom argument controls how much detail is shown. Larger number = more detail but more tiles to download.

Different Tile Providers

Just change the provider string — all are free with no API key:

Deriving the Bbox from Your Data

Instead of hard-coding coordinates, generate the bounding box directly from your data:

# Step 1: convert your data frame to an sf object
# coords tells sf which columns hold longitude and latitude
ChemData_sf <- st_as_sf(ChemData,
                         coords = c("Long", "Lat"),
                         crs = 4326)

# Step 2: get the bounding box and add a small buffer
# the + c(...) pads all four sides by ~0.4 km so points aren't at the edge
bbox_chem <- st_bbox(ChemData_sf) + c(-0.004, -0.004, 0.004, 0.004)

# Step 3: download tiles for that extent
Map_satellite <- get_tiles(
  st_as_sfc(bbox_chem),
  provider = "Esri.WorldImagery",
  zoom = 15,
  crop = TRUE,
  cachedir = here("Week_07", "data", "tiles_cache")
)

Overlay Point Data

Once you have a tile basemap, add ggplot layers on top exactly as you normally would:

ggplot() +
  geom_spatraster_rgb(data = Map_satellite) +
  geom_point(data = ChemData,
             aes(x = Long, y = Lat,
                 color = Salinity),
             size = 4) +
  scale_color_viridis_c() +
  coord_sf(crs = 4326) +
  theme_minimal()

Tip

Any geom_*() layer works on top of geom_spatraster_rgb() — points, lines, polygons. The tile is just another ggplot layer.

Add a Scale Bar and North Arrow

{ggspatial} provides two annotation functions that are spatial-aware — they calculate real-world distances and magnetic north automatically.

ggplot() +
  geom_spatraster_rgb(data = Map_satellite) +
  geom_point(data = ChemData,
             aes(x = Long, y = Lat,
                 color = Salinity),
             size = 4) +
  scale_color_viridis_c() +
  annotation_scale(           # scale bar
    location = "bl",          # bl = bottom-left
    bar_cols = c("yellow", "white")) +
  annotation_north_arrow(     # north arrow
    location = "tl") +        # tl = top-left
  coord_sf(crs = 4326) +
  theme_minimal()

Polish and Save

ggplot() +
  geom_spatraster_rgb(data = Map_satellite) +
  geom_point(data = ChemData,
             aes(x = Long, y = Lat, color = Salinity),
             size = 4) +
  scale_color_viridis_c(name = "Salinity (ppt)") +
  annotation_scale(location = "bl",
                   bar_cols = c("yellow", "white")) +
  annotation_north_arrow(location = "tl") +
  coord_sf(crs = 4326) +
  labs(title = "Maunalua Bay — Water Chemistry",
       caption = "Basemap: ESRI World Imagery") +

Interactive Maps with {leaflet}

Static maps are great for publications.
Interactive maps let you zoom, pan, and click on your data — and embed directly in HTML documents.

How Leaflet Works

{leaflet} builds maps by piping layers together with |> — similar in concept to ggplot’s +, but using pipes instead.

leaflet() |>                       # 1. create the map widget
  addProviderTiles(...) |>         # 2. add a basemap tile layer
  addCircleMarkers(...) |>         # 3. add your data as markers
  addLegend(...)                   # 4. add a color legend
  • leaflet() — initializes an empty map widget. Pass your data frame here.
  • addProviderTiles() — adds a basemap. Uses providers$Name to select from hundreds of free tile sources.
  • add*() functions — each one adds a new layer (markers, polygons, popups, legends…)
  • The result is an interactive HTML widget — it works in RStudio, Quarto HTML, and any web browser.

Your First Leaflet Map

leaflet() |>
  addProviderTiles(providers$Esri.WorldImagery) |>
  setView(lng = -157.762, lat = 21.274, zoom = 14)

Note

setView() centers the map on a specific location. lng and lat are the coordinates, and zoom works exactly like in {maptiles}.

The ~ Formula Notation

In leaflet, column names are written with a ~ prefix:

addCircleMarkers(lng = ~Long, lat = ~Lat, color = ~pal(Salinity))
  • ~Long means “use the Long column from the data frame”
  • It is leaflet’s equivalent of aes(x = Long) in ggplot
  • You will see ~ anywhere leaflet needs to reference a column

Tip

The ~ is leaflet’s way of saying “evaluate this as a formula against the data.” Without it, leaflet treats the argument as a fixed value, not a column reference.

Add a Color Palette

Leaflet needs a color function that converts numeric values to hex colors. colorNumeric() creates one:

# colorNumeric() returns a FUNCTION, not a color vector
pal <- colorNumeric(
  palette = "viridis",            # any RColorBrewer or viridis palette name
  domain = ChemData$Salinity      # the full range of values to map
)

# Use it by calling pal(value) — it returns a hex color
pal(30)  # what color does salinity = 30 get?
[1] "#1F978B"
pal(40)  # higher salinity → different color
[1] "#808080"

Add Data Points with Color

pal <- colorNumeric("viridis", domain = ChemData$Salinity)

leaflet(ChemData) |>           # pass data frame here
  addProviderTiles(providers$Esri.WorldImagery) |>
  addCircleMarkers(
    lng = ~Long, lat = ~Lat,   # which columns are coordinates
    color = ~pal(Salinity),    # apply our color function to Salinity
    radius = 6,
    fillOpacity = 0.9,
    popup = ~paste("Salinity:", Salinity, "ppt",  # click a point to see this
                   "<br>Site:", Site)) |>
  addLegend(
    pal = pal,                 # the same color function
    values = ~Salinity,        # which column drives the legend
    title = "Salinity (ppt)",
    position = "bottomright")

popup vs. label

popup — appears when you click a marker

addCircleMarkers(
  popup = ~paste("Site:", Site,
                 "<br>Salinity:", Salinity))

HTML tags work inside popups (<br> = line break).

label — appears when you hover over a marker

addCircleMarkers(
  label = ~Site)

Labels are plain text only (no HTML).

Tip

Use popup for detailed information (multiple fields, formatted text).
Use label for a quick identifier on hover.

Geocoding with {tidygeocoder}

Geocoding = converting a place name or address into latitude and longitude coordinates.

What Is Geocoding?

  • You know where you want to map, but not the exact coordinates
  • Geocoding services look up addresses and place names in a database and return lat/lon
  • {tidygeocoder} does this for free using:
    • OpenStreetMap (method = "osm") — best for landmarks and place names worldwide
    • US Census (method = "census") — best for US street addresses

Warning

Geocoding requires an internet connection and results depend on the service’s database. OSM is very good for well-known places but may fail on obscure locations or unusual search strings.

geo() — Convert a Place Name to Coordinates

geo() geocodes a single location string and returns a one-row tibble:

geo("University of Hawaii at Manoa", method = "osm")
# A tibble: 1 × 3
  address                         lat  long
  <chr>                         <dbl> <dbl>
1 University of Hawaii at Manoa  21.3 -158.
geo("Pearl Harbor, Oahu, Hawaii", method = "osm")
# A tibble: 1 × 3
  address                      lat  long
  <chr>                      <dbl> <dbl>
1 Pearl Harbor, Oahu, Hawaii    NA    NA

Tip

If a location returns NA, try a more specific search string — add the city, state, or country. OSM often needs more context for landmarks that share names across locations.

geocode() — Geocode a Data Frame

geocode() (note: no “r”) operates on a data frame and adds lat/lon columns:

oahu_sites <- tribble(
  ~place,
  "University of Hawaii at Manoa",
  "Honolulu International Airport",
  "Pearl Harbor National Memorial, Hawaii",
  "Diamond Head State Monument, Hawaii"
)

oahu_geocoded <- oahu_sites |>
  geocode(place, method = "osm") # geocode the 'place' column

oahu_geocoded
# A tibble: 4 × 3
  place                                    lat  long
  <chr>                                  <dbl> <dbl>
1 University of Hawaii at Manoa           21.3 -158.
2 Honolulu International Airport          21.3 -158.
3 Pearl Harbor National Memorial, Hawaii  21.4 -158.
4 Diamond Head State Monument, Hawaii     21.3 -158.

Map Geocoded Locations

leaflet(oahu_geocoded) |>
  addProviderTiles(providers$Esri.WorldImagery) |>
  addMarkers(
    lng = ~long, lat = ~lat,   # tidygeocoder always returns 'lat' and 'long'
    label = ~place)            # hover to see place name
